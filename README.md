# Hopewell Futuristic Frontend

A modern, 3D-led front-end concept for Hopewell Hospital, Ranchi.

## Included

- Next.js 15 + TypeScript
- Tailwind CSS
- React Three Fiber 3D hero
- Framer Motion interactions
- Responsive navigation
- Futuristic Centres of Excellence
- Interactive patient journey
- Searchable doctor cards
- Appointment assistant prototype
- Mobile-first responsive layout

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```
